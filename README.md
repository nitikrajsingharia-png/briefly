# Briefly — Daily Intelligence (v0.7)

A mobile-first, installable current-affairs reading app for UPSC/UPPCS preparation.

## Features
- Daily briefing, Prelims facts and Mains/PSIR perspectives
- Full-screen article reader with adjustable text size
- Local article bookmarks (Saved articles)
- Select and copy passages to paste manually into Notion or other notes
- Offline shell caching through a service worker
- No Notion API, no Cloudflare Worker and no credentials required

## Deploy on GitHub Pages
Upload the contents of this folder to the root of the existing `briefly` repository and commit. GitHub Pages will publish the update automatically.

## Install on Android
Open the GitHub Pages URL in Chrome or Samsung Internet, open the browser menu and choose **Add to Home screen** / **Install app**.

## Storage note
Bookmarks and reading preferences are stored locally in the browser on each device. They do not automatically synchronise between phone and laptop. Clearing browser site data may remove them.

## Content note
The bundled stories are demonstration/sample content. Replace them with verified daily reporting before relying on the app for current affairs.
